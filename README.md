# 🎙 かんたん録音 & トリミング

ブラウザだけで動く、録音・トリミングアプリです。**外部ライブラリやサーバー通信は一切なし**。録音した音声は端末の外に出ません（完全オフライン動作）。

👉 公開ページ: https://nakatadaiki1012-design.github.io/recording/

## できること
- **録音**：開始/停止ボタン、経過時間タイマー、録音中のリアルタイム波形
- **波形トリミング**：開始/終了スライダー、±0.1秒の微調整、前後の無音を自動カット
- **🚩 マーカー録音**：録音中に印をつけ、あとで「印から次の印まで」をワンタップ選択
- **🔁 くり返し＋速度変更**：0.5/0.75/1.0倍（音程はそのまま）でループ再生
- **🎵 音程測定**：音名＋基準A(440〜444Hz)からのセントずれ
- **🥁 テンポ測定**：おおよそのBPM
- **保存**：選択範囲だけをWAVで書き出し。日時の自動ファイル名、タグ、Enterで即保存、共有ボタン

すべて `index.html` の1ファイルに収まっています。ダブルクリックで開けますが、スマホでマイクを使うには https のページ（上の公開ページ）から開いてください。
