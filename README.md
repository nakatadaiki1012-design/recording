# Hibiki（響）— 録る・整える・磨く

ブラウザだけで動く、録音・トリミングアプリです。**外部ライブラリやサーバー通信は一切なし**。録音した音声は端末の外に出ません（完全オフライン動作）。

👉 公開ページ: https://nakatadaiki1012-design.github.io/recording/

## できること
- **🎚 エフェクト（19種）**：ノイズ削減・低い雑音カット・音量最大化・フェード・コンプ・低音/高音、ルーム/ホール/教会などの響き・エコー、コーラス・ラジオ風・ディストーション、キー上下・逆再生・無音詰め。強さスライダーで効き具合を調整、重ねがけ・元に戻す可（Web Audioのみ・オフライン）
- **📝 文字起こし（実験）**：話した言葉を文字化（Web Speech API・要ネット・Chrome/Android向け、iPhone Safariは非対応のことあり）
- **🎵 高音質録音（リニアPCM）**：通話用の音声処理と音量自動調整を切り、無圧縮のリニアPCMで録音。軽量（圧縮）モードにも切替可能
- **録音**：開始/停止ボタン、経過時間タイマー、録音中のリアルタイム波形
- **波形トリミング**：開始/終了スライダー、±0.1秒の微調整、前後の無音を自動カット
- **🚩 マーカー録音**：録音中に印をつけ、あとで「印から次の印まで」をワンタップ選択
- **🔁 くり返し＋速度変更**：0.5/0.75/1.0倍（音程はそのまま）でループ再生
- **🎵 音程測定**：音名＋基準A(440〜444Hz)からのセントずれ
- **🥁 テンポ測定**：おおよそのBPM
- **保存**：選択範囲を **MP3 / WAV** で書き出し。日時の自動ファイル名、タグ、Enterで即保存、共有ボタン
- **🎯 チューナー内蔵**：録音しながら／録音せずに、音程の針がリアルタイムで動く
- **🥁 メトロノーム内蔵**：BPM設定・カウントインしてから録音
- **📁 無音で自動分割＋一括保存**：長い合奏を区間ごとに切って、まとめて保存（名前に _1, _2 …）
- **🚩 印は録音後にも追加可能／⏮ 通し再生**
- **💾 自動保存＆復元**：うっかり閉じても「前回の録音」を復元
- **📚 保存一覧（ライブラリ）**：保存したものをアプリ内に一覧表示（聴き返し・再共有・削除）。ファイル名が同じでも自動で _2, _3 … を付けて区別
- **🎤 口頭コメント追記**：録音の末尾に一言コメントを録って付け足す（印つき）
- **📈 音程の推移グラフ**：のばした音が上ずる/下がるのを線で表示
- **🎧 イヤホン/ボタン操作**：メディアキーやスペース/Mキーで、画面を触らず録音・印
- **🌈 合奏の見える化**：波形を音程の正確さで色分け（緑＝合ってる〜赤＝ずれてる）
- **🎯 ロングトーン採点**：4秒のばした音の安定度を採点（★と点数）
- **🎼 単音の自動採譜**：吹いたメロディを音名＋簡易ピアノロールに
- **🎚 オーバーダブ（重ね録り）**：既存の録音に重ねて演奏を録音（イヤホン推奨）
- **🔁 ループ重ね録り（ルーパー）**：土台ループを作り、その上に演奏を何度も重ねて多重録音
- **🎭 ひとりアンサンブル**：メロディに3度/5度/8度のハモリを自動生成して重ねる
- **🗺 合奏まるごと通知表**：音程・テンポ・音量を成績表の画像にまとめて書き出し/共有

すべて `index.html` の1ファイルに収まっています。ダブルクリックで開けますが、スマホでマイクを使うには https のページ（上の公開ページ）から開いてください。
